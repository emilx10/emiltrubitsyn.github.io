# Before you send this to recruiters

A checklist of every placeholder in the site. Search for these strings to find them fast.

## Must replace
- [ ] **Name**: "Alex Carter" appears in `index.html` (title tag, hero, og:title, footer) — find/replace across the file.
- [ ] **Hero pitch**: the one-line description under your name.
- [ ] **Inspector card**: role / engine / focus / status values in the hero.
- [ ] **Project 1 and Project 2**: title, tags, description, and links (`href="#"`) — currently placeholders.
- [ ] **Project media**: each `.media-placeholder` div has a comment showing how to swap in a `<video>`, `<img>` (gif), or `<iframe>` (WebGL build).
- [ ] **About bio**: replace the placeholder paragraph in the About section.
- [ ] **Skills lists**: edit to match your actual tools/experience.
- [ ] **Contact links**: real email, LinkedIn URL, GitHub URL in the Contact section.
- [ ] **Resume file**: add your actual PDF at `assets/resume.pdf` (the "Download resume" button already points there).
- [ ] **Favicon**: currently a generated "A" letter icon — replace if you want something custom.

## Optional but recommended
- [ ] Add real screenshots/gifs to `assets/projects/` and reference them in the project media placeholders.
- [ ] Double check all external links (LinkedIn, GitHub, project links) actually work.
- [ ] Test on your phone — resize your browser window narrow to check mobile layout.
